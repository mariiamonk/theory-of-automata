### О проекте
Библиотека для работы с регулярными выражениями, реализующая полный цикл обработки: от синтаксического анализа до компиляции в детерминированные конечные автоматы (ДКА). Поддерживает все основные операции, включая именованные группы захвата, диапазонные повторы и сложные комбинации языков.

## Поддерживаемые операции

| Операция                  | Метасимвол(ы)      | Пример       |
|---------------------------|--------------------|--------------|
| `Или`                     | `|`                | `r1|r2`      |
| `Конкатенация`            | (опционально `-`)  | `r1r2`, `r1-r2` |
| `Позитивное замыкание`    | `+`                | `r+`         |
| `Опциональная часть`      | `?`                | `r?`         |
| `Любой символ`            | `.`                | `.`          |
| `Повтор в диапазоне`      | `{x,y}`            | `r{2,5}`, `r{,3}`, `r{4,}` |
| `Именованная группа захвата` | `()` + имя       | `(?<name>r)` |
| `Использование группы`    | `\k<name>`         | `\k<name>`   |

## Особенности реализации

- **Компиляция в ДКА**: Полный цикл преобразований:  
  `РВ → НКА → ДКА → Минимизация ДКА`
- **Экранирование метасимволов**: Через символ `&` (например: `&.` означает точку)
- **Оптимизация**: Автоматическая минимизация ДКА после компиляции
- **Группы захвата**: Поддержка анонимных и именованных групп
- **Современные операции**: Полная поддержка расширенного синтаксиса

## Основные классы
-  **AST** - реализация абстрактного синтаксического дерево, которое отвечает за парсинг
-  **NFA** - преобразует `АСТ → НКА`
-  **DFA** - алгоритм Томпсона преобразует `НКА → ДКА`
-  **MinimizedDFA** - реализзация алгоритма Хопкрофта и основных операций над языком
-  **Regex** - библиотека для работы с регулярными выражениями
